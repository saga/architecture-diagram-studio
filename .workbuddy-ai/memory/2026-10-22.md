## 支持 draw.io 全部图形的架构评审（只读，未改代码）

产出 `DRAWIO-DIAGRAM-TYPE-READINESS-REPORT.md`（仓库根目录，554 行）。

核心结论：当前架构是「以 draw.io 为渲染器的 C4/流程图/时序图生成器」，
`DiagramDocument` 是唯一真相源，draw.io XML 只是投影。要支持全部 draw.io
图形必须推翻这条前提，改成双轨（semantic / native）。

### 关键证据（后续改动可直接引用）

- `src/model/types.ts:1` `DiagramKind` 封闭；`:148` 白名单硬卡；`:149` theme 字面量。
- `src/design/styles.ts:10` 形状只有 rect|pill|diamond；`DiagramCanvas.tsx:105-113` 对应三种 path。
- `src/import/drawio.ts` 完全忽略 `parent` → group/container/swimlane 层级全丢；
  `:96` 标签只取第一个 `<div>` → UML 类属性区、ER 列全丢；`:124` 无 geometry 直接丢；
  `:148-149` 端点未映射的边直接丢。
- 多页：未压缩走 `:79` 的 `querySelectorAll` 会把所有页合并；压缩走 `:40-69` 只解第一页。
- `src/export/drawio.ts:21`/`:44` `parent="1"` 硬编码 → 结构上无法表达嵌套；
  `:142-144` 只产出单个 `<diagram>`。
- `src/App.tsx:480-484` `commitDocument` 不传第三参就清空 `nativeXmlOverride`
  → **任何 Studio 编辑都会用 `toDrawioXml()` 重建的 XML 覆盖原生 XML**（数据丢失主因）。
- `src/App.tsx:768` 导入后无条件 `requestServerLayout` → 手绘布局被 ELK 重排。
- `src/App.tsx:596-609` `changeKind` 用 `FIXTURES[kind]()` 整篇替换 → kind 实为「重置示例」。
- `server/copilot-server.ts:1033` 等 5 处 `requiresLayout = next.kind !== "sequence"`
  → 非时序图的任何 AI 编辑都全量重排。
- `server/diagram-domain.ts:7` 500 节点上限；`:9-11` role/kind 白名单。
- `server/copilot/diagram-tools.ts:74` 明确禁止 AI 写 XML → 原生轨 AI 无法工作。
- `DrawioFrame.tsx:172-194` 已在往 iframe 注入 `<style>` → 原生轨套设计语言技术上可行，只是没做。

### 建议路线

阶段 0（3–5 人日，止血）：passthrough 保留未知 cell、导入不自动重排、

### 实测结论

- 节点映射 100%（28,324），**边只映射 32.8%**（8,846 → 2,899）。
- **P0-1**：`drawio-xml-source.ts:29` 的 cell 正则 `[^>]*` 会吞掉自闭合标签的 `/`，
  把整段 root 合成一个 cell → `cellMap` 永远没有 `"1"` → `:40` 恒返回 null
  → `canEditInStudio` 恒 false、`patchDrawioXml` 恒 null → App 强制切 Freeform。
  **连 Studio 自己导出的 XML 都过不了**；`drawio-xml-source.test.ts` 2 项已红。
- **P0-2**：`import/drawio.ts:292-293` 用正在累积的 `nodes` 判端点存在，
  边排在顶点前就被丢 → 4,456 条边（50.4%）丢失，217 个文件全丢。
  `templates/basic/flowchart.xml` 5 条边全丢。
- **P0-3**：`:262-268` 把嵌套 cell 的父级相对坐标当绝对坐标 → 10,761 个 cell
  堆到原点（ER 表行、UML 属性、泳道任务）。导出侧 `export/drawio.ts:29` 仍硬编码 `parent="1"`。
- **P0-4**：`:274-275` 空 value → `"New node"`，占全部节点 **51.2%**（14,504 个）。
- P1：多页只取第一页（181 页静默丢）；92% 节点判为 `domain`（12,887 个 `shape=` 未映射）；
  1,491 条边连到嵌套 cell；draw.io 原生时序图不被识别（kind 仍 c4）；
  mxlibrary 报 `Invalid input`。
